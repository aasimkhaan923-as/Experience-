Key Instrumentation Formulas

4-20 mA Signal Loop:

I = 4 + 16 × (PV / 100)

RTD Pt100 Resistance:

Rt = R0 × (1 + α × T) where α = 0.00385 Ω/Ω/°C

Terms & Dictionary

Hysteresis:

The maximum output difference for a given input when approached from increasing vs decreasing directions.

LVDT:

Linear Variable Differential Transformer - an electromechanical transducer for measuring displacement.
