Instrumentation Formulas Quick Reference

Signal Current Loop Formula:

I = 4 + 16 × (PV / 100)

RTD Resistance Formula (Pt100):

Rt = R0 × (1 + α × T)

Dictionary & Reference Terms

Hysteresis Error:

The maximum difference in output value for a given input value when approached from increasing and decreasing directions.

LVDT:

Linear Variable Differential Transformer - an electromechanical transducer used for measuring linear displacement.

How-To Calibration & Troubleshooting Guides

  • How to Calibrate a 4–20 mA Transmitter: Connect a calibrated multimeter in series, apply 0% process input, adjust zero screw to 4.00 mA, apply 100% input, adjust span screw to 20.00 mA.
  • How to Test RTD Sensors: Measure resistance across terminals using a DMM. At 0°C, Pt100 should read exactly 100.0 Ω.
